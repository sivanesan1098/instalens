How ReelBrief Extracts & Separates Links

1. Video Stream & Frame OCR Links: Samples keyframes from the Instagram video (via yt-dlp + OpenCV + pytesseract) and audio transcript (faster-whisper) to capture URLs flashed on screen or spoken aloud, tagging each with its timestamp.

2. Caption & Bio Links: Parses the post caption separately so URLs in the description or "link in bio" pointers are never mixed up with on-screen video links.

3. Running the backend: Install dependencies and start the server with uvicorn backend:app --host 0.0.0.0 --port 8000. The frontend is served at / and calls /api/extract — one process serves both, so it's deployable as a standalone web app (container, Render, Fly, etc.).
